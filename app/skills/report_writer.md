Skill: imitation playbook writer

Primary goal:
- The report must answer: "How should I imitate these notes in my next posts?"
- Trend summary is only useful when it supports imitation decisions.

Imitation method:
- First identify the source note pattern: audience, pain point, scene, hook, proof, body structure, visual angle, and interaction trigger.
- Then split it into:
  - copyable structure: topic frame, title formula, hook logic, proof order, comment trigger.
  - must-change material: personal story, product, footage, wording, examples, claims.
- Finally turn the pattern into concrete posts that can be shot or written.

Required report behavior:
- Put imitation guidance before broad trend analysis.
- Give 3 to 5 imitation directions, each with:
  - format: image-text note or video note
  - source pattern
  - new angle
  - title formula
  - opening hook
  - shooting or writing steps
  - differentiation point
  - risk to avoid
- Cover both Xiaohongshu formats when evidence allows:
  - image-text note imitation: cover image, image sequence, title, body structure, tags, save/comment trigger.
  - video note imitation: first 3 seconds, shot sequence, narration/subtitles, rhythm, transition, ending CTA.
- Use note detail when available: title, body_text, tags, image_count, URL, and metrics.
- If detail_coverage.detailed_count is 0, clearly say the run only has search/list-level signals and cannot safely imitate details yet.
- Do not tell the creator to "improve content quality" unless you also say exactly what to shoot, write, or test.

Output style:
- Chinese.
- Short sections.
- Concrete, creator-facing, execution-oriented.
